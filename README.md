Pick-to-Wall System for Farmacity
This project is a Pick-to-Wall system designed for Farmacity, an Argentine pharmacy chain. 
It allows for efficient order picking by scanning items from orders and activating lights in the corresponding positions on the wall, 
guiding warehouse staff through the process. 
The system ensures a streamlined and accurate picking operation by lighting up the correct location for each item.


Features:
Order Management: The system receives and processes waves of orders, ensuring that items are picked in the correct order.
Lighting System: Lights are activated at the positions where items are located, guiding the staff to the right shelf or bin.
Completion Notifications: Once an item is picked from a position, a light in the next position turns on, indicating the next task.
Hardware Integration: Built using a Raspberry Pi to control the lights and a barcode scanner to scan items.


Technology Stack:
Python: Used for the backend, handling the logic and communication between the system components.
HTML: Used for the user interface to manage and visualize orders.
Raspberry Pi: Used to control the lighting system and interact with the barcode scanner.

This system aims to optimize the picking process in the warehouse, reduce errors, and improve overall efficiency for Farmacity's logistics operations.

Sistema Pick-to-Wall para Farmacity
Este proyecto es un sistema Pick-to-Wall diseñado para Farmacity, una cadena de farmacias de Argentina. 
Permite una recolección de pedidos eficiente al escanear los artículos de las órdenes y activar luces en las posiciones correspondientes en la pared, 
guiando al personal del almacén durante el proceso. El sistema asegura una operación de recolección más ágil y precisa al iluminar la ubicación correcta de cada artículo.


Características:
Gestión de Pedidos: El sistema recibe y procesa olas de pedidos, asegurando que los artículos sean recolectados en el orden correcto.
Sistema de Iluminación: Se activan luces en las posiciones donde se encuentran los artículos, guiando al personal hacia la estantería o compartimiento adecuado.
Notificaciones de Finalización: Una vez que un artículo es recogido de una posición, se enciende una luz en la siguiente posición, indicando la siguiente tarea.
Integración de Hardware: Creado utilizando una Raspberry Pi para controlar las luces y un escáner de códigos de barras para escanear los artículos.


Tecnologías Utilizadas:
Python: Utilizado para el backend, manejando la lógica y la comunicación entre los componentes del sistema.
HTML: Utilizado para la interfaz de usuario que gestiona y visualiza los pedidos.
Raspberry Pi: Usada para controlar el sistema de iluminación e interactuar con el escáner de códigos de barras.

Este sistema busca optimizar el proceso de recolección en el almacén, reducir errores y mejorar la eficiencia general de las operaciones logísticas de Farmacity.
